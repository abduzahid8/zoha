# Zoha — Web

Landing site for [Zoha](https://github.com/CopilotKit/Zoha), a personal agent that does the work and shows you how. Self-hosted, built on CopilotKit.

Adapted from the [AURA agency template](https://github.com/YusufCeng1z/svelte-gsap-template).

## Stack

- **Framework:** Svelte 5 (Runes) + SvelteKit
- **Styling:** Tailwind CSS v4
- **Animation:** GSAP 3 (ScrollTrigger, ScrollToPlugin)
- **Smooth scroll:** Lenis

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

All copy lives in `src/lib/i18n/en.js` and `src/lib/i18n/uz.js` (English + Uzbek). Facts about the product come from the [Zoha repository](https://github.com/CopilotKit/Zoha) — do not claim features that are not shipped there.
